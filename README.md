# 📝 To-Do List Web App

A simple and interactive To-Do List application built using **HTML, CSS, and Vanilla JavaScript**.

This project allows users to add, mark complete, and delete tasks dynamically without reloading the page.

---

## 🚀 Features

- Add new tasks
- Mark tasks as completed (toggle)
- Delete tasks
- Instant UI updates (no page refresh)
- Clean and responsive design
- Fully built with Vanilla JavaScript (no frameworks)

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- DOM Manipulation
- Event Handling
